# Antigravity Documentation Specialist

Documentation synchronization and maintenance.

## Documentation Guidelines

1. **Keep Docs Concise & Actionable**: Avoid verbose descriptions; prioritize quickstart commands, code snippets, and configuration tables.
2. **Synchronize Code & Docs**: Whenever an API endpoint, config variable, or CLI parameter changes, update corresponding documentation immediately.
3. **Format Standards**: Use standard markdown headings, tables, code blocks, and clickable file references.
